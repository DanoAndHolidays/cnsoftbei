## 1. 背景与目标

为已基本完成的 "学习智能体系统"（React + TypeScript + Vite 多智能体学习平台）制作**一份汇报 PPT**，同时满足两个使用场景：

1. **课程结课汇报** — 老师 + 同学受众，10-15 分钟讲解
2. **中国软件杯 A3 参赛预演** — 评委审视维度（创新 35% / 功能 45% / 文档 10% / PPT 10%）

成功标准：

- 19 页内完整呈现"画像 → 路径 → 资源 → 练习 → 辅导 → 评估"端到端闭环
- 第 4 页可直接对照 A3 赛题 5 项功能 + 4 项非功能需求
- 视觉上既严肃（适合答辩）又有 AI/教育产品的现代感
- 通过 `python-pptx` 生成真正的 `.pptx` 文件，会场任何 Office/WPS 可播放、可二次编辑

---

## 2. 范围

**包含**:
- 19 页幻灯片生成代码（`ppt/slides/s01_cover.py` ~ `s19_closing.py`）
- 视觉组件库（`ppt/components/`）
- 自绘架构图、流程图、雷达图
- 8 张现有真实截图的引用与排版
- 评估页面 mockup（替代缺失的 Assessment 截图）
- 一份 README（如何运行 / 如何迭代）

**不包含**:
- 7 分钟演示视频（赛题另一个交付物，本设计不涉及）
- PDF / 网页版本（仅交付 .pptx）
- 系统开发说明书等配套文档
- 切换 LLM 供应商到科大讯飞星火（项目当前用 MiniMax M2.7；PPT 用通用 "大模型 API" 措辞规避；如真要参赛需另行处理）

```
│   ├── s07_tech_stack.py
│   ├── s08_agent_profile.py
│   ├── s09_agent_resource.py
│   ├── s10_agent_path.py

│   ├── layout.py                   # 页眉页脚 / 章节分隔
│   ├── shapes.py                   # 几何分割线 / 色块 / 胶囊标签

│
└── output/
    └── 学习智能体系统_汇报PPT.pptx
```

### 6.2 依赖

**Python ≥ 3.10**（用于 `match`/`case` 语法与新版 type hints；如果用户环境只有 3.8/3.9，会降级使用 if/else 实现）

```txt
python-pptx==1.0.2
Pillow==11.0.0
matplotlib==3.10.0
```

### 6.3 关键技术决策

| 问题 | 方案 | 理由 |
|---|---|---|
| 字体兼容 | 微软雅黑 + 备选 Arial | Windows 默认，会场必有 |
| 截图插入 | 等比缩放到 4:3 框，加 1pt 浅灰边框 | 防变形 |
| 自绘架构图 | python-pptx 形状 + 文本框拼装 | 不依赖图床 / 外链 |
| 自绘雷达图 | matplotlib → PNG → 插入 | 比纯形状画快 10× |
| 代码片段着色 | 自写 60 行染色规则（关键字 / 字符串 / 函数 / 注释 4 色） | 不引入 pygments |
| 流程图 | 复用 `flow_diagram.py` | 风格统一 |
| 页眉页脚 | `apply_chrome(slide, chapter, page)` 通用函数 | 避免重复 |

### 6.4 使用流程

```bash
# 第一次
cd ppt
pip install -r requirements.txt
python generate.py
# → output/学习智能体系统_汇报PPT.pptx

# 局部重跑
python generate.py --only s10
python generate.py --from s08 --to s12
```

生成后用 PowerPoint / WPS 打开手动微调（改文字、换截图、调字号）。

## 9. 风险与开放问题

| 风险 | 影响 | 缓解 |
|---|---|---|
| Assessment 截图缺失 | 第 12 页视觉单薄 | python-pptx 自绘 mockup 替代；后续可手动替换为真截图 |
| AI 模型供应商不符（MiniMax vs 星火） | 比赛合规风险 | PPT 用通用"大模型 API"措辞；建议参赛前另行处理 |
| 微软雅黑在 Mac 上替代 | 跨平台字体差异 | 设置备选 PingFang SC / 思源黑体 |
| matplotlib 雷达图渲染失败 | 第 12 页缺图 | fallback 为 python-pptx 多边形 + 折线手绘 |
| 自绘架构图复杂度高 | 第 6 页可能耗时 | 分两轮：先简化版（4 矩形+箭头）跑通，再加细节 |
